CHALLENGE 5 • MULTIPLE DECISIONS

📊 Student Result Checker

Build a program that reads an integer mark.

80+ → Excellent
60–79 → Good
40–59 → Keep practising
Below 40 → More practice needed
mark = int(input("Enter your mark: "))

if mark >= 80:
    print("Result: Excellent")

# Complete the program
After the first if, use elif mark >= 60:, then another elif, then else.

Test: 95, 80, 72, 60, 45, 39.
